# README visuals

- `gitsettle-mark.svg`: the application's yellow-circle mark, using Lucide GitMerge geometry. The SVG retains its upstream ISC notice and an accessible title/description.
- `readme-overview.png`: a genuine live testnet capture from `../screenshots/live/work-queue.png`, cropped to its top 1440 × 1020 pixels through the first settled bounty row, then resized to 1200 × 850 with Lanczos. No text, values or states were added. PNG metadata records the source path, SHA-256 and derivation.
- `sister-projects.svg`: an original comparison graphic for GitSettle and AgentGuard by CodeMaster Labs. It distinguishes the separate products and labels the shared pinned MIT recipient/text-check baseline. The reused GitMerge geometry retains its ISC notice; the SVG has an accessible title/description.

The main README links the complete live screenshots and machine-readable payout evidence separately. These assets are documentation illustrations, not additional transactions or new settlement evidence.
